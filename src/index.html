    Generate uses Ollama on this computer to read these selected images and any saved text. No API key or per-request charge. Review wording, symbols, labels, and image boundaries before applying.

    Enable local AI on your computer

    Install Ollama (0.12.7 or newer) and Node.js 22 or newer. Keep Ollama running, then download the model once:

    ollama pull qwen3-vl:4b-instruct

    Qwen3-VL 4B uses Apache 2.0-licensed weights. The download is about 3.3 GB; running it needs additional memory. A computer with 16 GB RAM is a practical starting point, and CPU-only generation can be slow.

    In this repository's folder, run:

    npm ci
npm start

    Open http://localhost:4173. If Ollama is stopped, open the Ollama app or run ollama serve, then choose Check Ollama again. No key or .env file is needed for the default setup.

    The downloaded HTML and public static site keep the manual tools available. Local AI needs the running app and installed model. The app never downloads a model automatically.

    From problem set to worksheet.

    1. Upload. Add one or more PDFs or images. Manual editing stays in your browser.
    2. Select. Drag around a question, or review automatic suggestions. Adjust crops with handles or percentage inputs.
    3. Format automatically. Select the whole problem and choose Format with AI. Generate a proposal, check the original beside the PDF preview, then apply it. AI requires the local app and an installed Ollama vision model; Generate processes the selected content on your computer. A problem card can format up to six original regions together, including scanned pages. Restore original undoes formatting.
    4. Reflow prose manually. Select only the instructions and choose Reflow selected text. Review the words, then add the original equation or diagram as a crop with Q. Scans need typed or pasted text.
    5. Combine. Select a problem card, navigate to another page, then append a region for its continuation.
    6. Arrange. Move cards up or down. Adjust writing space, scale, and page breaks. Balanced spacing spreads spare room below whole problems; choose Compact for exact writing heights.
    7. Preview & export. Check the actual PDF. For oversized crops, reduce scale, split the selection, or choose Fit to one page.

    Suggestions use numbered text, not OCR. Scans need manual selection. Keep only the question in each crop. P adds a new selection; Q appends it to the selected problem. Shortcuts pause while typing or using a dialog. Settings are remembered for new problems and future visits; refreshing clears the imported files and problem list.
