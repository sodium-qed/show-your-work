# Show Your Work v1.0.2

Fixes a remaining page-reading failure where visible exercises such as `42, 47, 52` could still be reported as missing after v1.0.1.

## Fixes

- Automatically read the rendered page with OCR when PDF text analysis finds no problem numbers, even if the PDF exposes plenty of ordinary prose. Some PDFs store their exercise labels separately from the readable text.
- Preserve horizontally slanted PDF text that was incorrectly discarded as rotated text. Genuinely rotated baselines remain excluded.
- Add **Read page visually** above the source page. Use it to recover labels missing from a partially readable text layer, then enter the requested numbers again. A replacement must retain the previously detected numbers and add new ones before it replaces existing problem boxes.
- Keep rendered pages available when the OCR download fails, continue reading later PDF pages, and show a persistent warning with recovery instructions. Retrying in the same tab now makes a fresh module request after an initial download failure.
- Preserve selected problems, drawn-box geometry, and unambiguous work-area choices when a visual reread updates page detection. Refresh selected crops and direction groups, and wait for queued reading before applying a number request.
- Prevent an uncorroborated number token inside an existing text segment from becoming a new problem merely because OCR left a wide space before it. This avoids cutting a problem short at an equation constant.

## Download and update

Download `show-your-work-1.0.2.zip` and extract the complete folder. Stop the old local server, then run this inside the new folder:

```bash
npm start
```

Open `http://localhost:4173`, reload the app, and reopen the original textbook files. Node.js 22.3.0 or newer is required for the included server; the packaged download does not need `npm install`. Static hosting is also supported.

If a visible exercise still has no box, navigate to its source page, click **Read page visually**, wait for reading to finish, then enter its number again. **Draw** remains available for ambiguous labels.

`SHA256SUMS` verifies the ZIP. `version.json` records the version and exact source commit.
