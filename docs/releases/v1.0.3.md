# Show Your Work v1.0.3

Fixes the reproduced selection, reading, and cropping failures on scanned mathematics and multi-column textbook PDFs.

## Selection and requests

- A standalone number list or range replaces the numbered selection. Explicit `add` and `remove` requests remain incremental. Unnumbered manual boxes are kept, and a selected manual crop takes precedence over the automatic crop for that exercise.
- Resolve exclusions before selecting problems. `1-50, omit (1, 2, 6, 7, 9, 12, 15, 16, 19, 20, 22, 42), look at all pages` requests exactly 38 exercises. Local AI cannot reinterpret this literal request as removing every problem.
- Treat “look at all pages” as source-page scope. It does not change the number of printed sides.
- Prefer a main exercise over its duplicate in the same file's explicitly marked Quick Review section. Preserve review-only exercises and unrelated numbering in other files.
- If some requested labels are missing, select the detected subset and report the missing labels. If none are found, preserve the previous selection. An explicitly empty set after exclusions clears numbered selections.

## Page reading and crops

- Infer independent columns before assigning paragraph boundaries. A lower label in a neighboring column no longer cuts the current exercise short or takes its continuation text.
- Measure scanned exercise labels from their own ink. Tall integrals and stacked fractions no longer inflate the label font size or move its baseline.
- Cross-check difficult math scans with sparse OCR and focused reads of the number columns. Conflicting labels receive a local reread. Proposed numbers must have visual evidence; the detector does not fill gaps by inventing a sequence.
- Combine reliable native PDF text with corroborated visual reading for incomplete text layers. Keep readable native geometry and use OCR to recover missing labels and content.
- Keep original formula and figure pixels within the exercise's column and row boundaries.
- Load the bundled PDF image decoders so JPEG2000 illustrations render in the source page and exported problems.
- Use PDF image placements to preserve pale illustration edges that dark-ink detection alone cannot find. Exclude page scans, exercise text, and small label images from these figure bounds.
- Distinguish outlined printed diagram fills from highlights while preserving genuine blue highlights and circles.
- Preserve warm shaded illustrations that resemble highlighter colors. This requires native image bounds, a broad filled shape, and tone variation; thin strokes, rings, and uniform marker blocks remain highlights.

## Download and update

Download `show-your-work-1.0.3.zip` and extract the complete folder. Stop the old local server, then run this inside the new folder:

```bash
npm start
```

Open `http://localhost:4173`, reload the app, and reopen the original textbook files. Node.js 22.3.0 or newer is required for the included server. The release includes the PDF libraries and does not need `npm install`.

`SHA256SUMS` verifies the ZIP. `version.json` records the exact source commit.

## Reading model and limits

Page reading uses the PDF text layer, Tesseract neural OCR, and layout analysis together. The optional Local AI is a text model for interpreting requests; it does not inspect page images. This release adds no vision-model download, external inference service, or API-key requirement.

OCR assets and the optional request model download when needed; they are not included in the ZIP. Files are processed locally in the browser. Serve the app through HTTP/HTTPS. Each file is limited to its first 80 pages. Unclear scans or unusual layouts may still need **Read page visually** or **Draw**. A problem whose text and figure lie far apart can retain substantial blank space in its rectangular crop. Grayscale printing can increase contrast in shaded artwork; content already clipped in the source PDF is not reconstructed.
