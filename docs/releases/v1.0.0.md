# Show Your Work v1.0.0

First published release of the browser-based worksheet formatter.

## Features

- Extract highlighted problems from textbook PDFs or photos; select by problem number/range or draw a box manually.
- Remove highlighter marks while retaining original math, diagrams, problem numbers, shared directions.
- Export printable exam sheets with adjustable page counts, spacing, columns, Letter/A4 paper, polar grids, graph paper, answer lines.
- Process documents locally in the browser with bundled PDF.js/pdf-lib. No API key required.
- Read requests with built-in rules; optionally enable the Qwen3.5-0.8B model through WebGPU.

## Download

Download `show-your-work-1.0.0.zip`, extract the complete folder, then run:

```bash
npm start
```

Open `http://localhost:4173`. Node.js 22.3.0 or newer is required for the included local server. No dependency installation is needed for this packaged download. Static hosting is also supported.

`SHA256SUMS` verifies the release archive. `version.json` records its version plus source commit.

## Requirements / limits

- OCR downloads Tesseract.js assets when needed. Optional local AI requires WebGPU plus an initial model download (approximately 470 MB). These assets are not included in the ZIP.
- Files must be served through HTTP/HTTPS; use `npm start` locally.
- The built-in rule reader handles a limited set of phrases; the broader model-assisted evaluation was not rerun for this release.
- Documents over 80 pages are not read. Use manual selection for unnumbered prompts.
