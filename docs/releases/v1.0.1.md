# Show Your Work v1.0.1

Fixes problem-number selection that could leave the exam unchanged or report "added nothing" even when the requested exercises were visible on the page.

## Fixes

- Recognize plain exercise labels such as `43`, `45`, and `57` when supported by aligned numbering or a named exercise range. Guards keep ordinary constants, decimals, years, and page numbers out of the regression selections.
- Handle PDF text layers that split a label into separate number and punctuation runs, or join a label directly to a word-problem title.
- Recognize abbreviated directions such as `Exer. 43–44:` and keep their instructions attached to the correct problems.
- Resolve explicit number lists immediately through the rule reader, even when Local AI is on.
- Wait for all queued files and pages before applying number requests, including files added while the optional model interprets a request.
- List missing numbers in a warning. Partial requests retain found problems; entirely missing requests preserve the current selection instead of reporting a successful addition.

## Download and update

Download `show-your-work-1.0.1.zip`, extract the complete folder, then run:

```bash
npm start
```

Open `http://localhost:4173`. Node.js 22.3.0 or newer is required for the included local server. No dependency installation is needed for the packaged download. Static hosting is also supported.

Stop the old local server before starting the updated folder. Reload the app and reopen the original textbook files so their problem labels are analyzed with the new detector.

`SHA256SUMS` verifies the archive. `version.json` records the version and exact source commit.

## Verification

- All 16 unit/regression tests passed, including six new detector regressions and explicit-list behavior with a ready model-worker stub.
- Chromium reproduced the original plain-label failure before the fix, then passed two original, generated two-page fixtures covering plain labels, split punctuation, and joined titles.
- Both `Problems 43, 45, 57` and `42, 54, 57` selected exactly the requested exercises in those fixtures.
- Browser checks covered unfinished file reads, partial and missing requests, preservation of existing selections, direction ranges, and valid two-page PDF downloads.
- The original highlighted sample still selected the expected 11 problems and exported a valid two-page PDF.
- The extracted release bundle passed both browser workflows without installed runtime dependencies. The ZIP contains 218 files.
- The rule-reader evaluation remained at the documented 20/28 baseline. The full optional WebGPU model evaluation was not rerun.

## Requirements and verification limits

- The supplied screenshots were inspected. Their label layouts were reproduced in regression fixtures; the original source PDFs were not available for verification.
- OCR downloads Tesseract.js assets when needed. Optional Local AI requires WebGPU and an initial model download; these assets are not included in the ZIP.
- Serve the app through HTTP/HTTPS. Documents over 80 pages are limited to their first 80 pages. Ambiguous or unreadable labels may still need Draw.
